# To do

Feature ideas for OmniRead. Tick one off when it ships.

- [x] **Backup and restore** — export and import library folders, reading positions, bookmarks, highlights and
  settings as one file, for moving to another PC or recovering after a reinstall.
- [x] **Export highlights and notes** — save a book's highlights and notes as Markdown or plain text, grouped by
  chapter.
- [x] **Collections and tags** — user-made shelves ("To read", "Favourites", a series) that hold books regardless
  of their folder, alongside the folder shelves.
- [x] **Library search and filters** — a search box on the library page that filters by title or author while
  typing, plus filters for format and for unread, in progress or finished.
- [x] **Metadata and cover editing** — correct a title or author, or choose a cover image, for books whose files
  carry none.
- [x] **Read-aloud controls** — pause and resume, skip back or forward a sentence, and a sleep timer that stops
  after a set time or at the end of the chapter.
- [x] **Export as audiobook** — render a chapter or a whole book to audio files with the chosen voice, in the
  background.
- [x] **Focus mode** — a mode that dims everything except the current paragraph or line.
- [x] **Reading goals and history** — a daily reading goal with a streak, and a chart of time read per day, built
  on the statistics already recorded.
